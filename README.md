## Tech Stack

- React 18 with functional components + Hooks
- React Router DOM v6
- CSS (floating label inputs, custom radio buttons)
- Inter font (Google Fonts)

---

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## Build & Deploy

```bash
npm run build
```

Deploy the `build/` folder to Vercel or Netlify.
